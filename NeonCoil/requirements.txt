# NEON COIL — the entire dependency list.
#
# There is no third entry, and there are no asset files anywhere in the project: every sprite,
# gradient, icon, particle and sound effect is generated at runtime from these two libraries.
#
# pygame-ce is the maintained community fork of pygame. It imports as `pygame`, so plain
# `pygame` also works if that is what is already installed — but ce is what this was built and
# tested against, and it is the one that gets wheels for new Python releases promptly.
pygame-ce>=2.4

# OPTIONAL, and the game checks rather than assumes. Used for the things defined per pixel rather
# than per shape — radial glows, the background wash, the vignette, alpha premultiplication and
# the sound bank — where a Python loop over a 1280x720 alpha channel takes most of a second and
# the array form takes milliseconds.
#
# Every one of those has a pygame-only fallback, because the WebAssembly build cannot have numpy:
# pygbag publishes a wheel for it built against a runtime version it no longer ships. Install it
# for the desktop build; the browser build runs the fallbacks and looks near-identical.
numpy>=1.24
